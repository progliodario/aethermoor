# Code of Conduct

This is a short code of conduct adapted from the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (CC BY 4.0).

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, body size,
disability, ethnicity, gender identity and expression, level of experience, nationality, appearance, race, religion,
or sexual identity and orientation.

## Expected behavior

- Be respectful, constructive and patient. Assume good intent.
- Give and accept feedback gracefully.
- Focus on what is best for the project and the community.

## Unacceptable behavior

- Harassment, insults, discriminatory language, personal or political attacks
- Sexualized language or imagery, and unwelcome attention
- Publishing others' private information
- Content that violates the project's content rating (see CONTRIBUTING)
- Other conduct reasonably considered inappropriate in a professional setting

## Enforcement

Maintainers may remove, edit or reject contributions that violate this code, and may temporarily or permanently ban
contributors. Report problems privately to the maintainers through GitHub (a private security advisory or a direct
message to a maintainer). All reports are reviewed and kept confidential.

This code applies in all project spaces: issues, pull requests, discussions and reviews.
