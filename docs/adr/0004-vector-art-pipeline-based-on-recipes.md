# ADR 0004: Vector art pipeline based on recipes

- Status: accepted
- Date: 2026-11-01

## Context

The game is 2D vector/minimal, generated by code, with the ability to replace art with files later.

## Decision

Art is described as JSON recipes (paths, gradients, strokes, rigs, clips). Each client rasterizes recipes into texture atlases at device scale: ThorVG on desktop, `android.graphics` on Android. `overrides/` can replace any recipe with SVG/PNG.

## Consequences

Resolution independent and file-free. Small antialiasing differences between rasterizers are accepted and covered by tolerant golden tests.
