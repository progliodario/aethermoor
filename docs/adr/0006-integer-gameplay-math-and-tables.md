# ADR 0006: Integer gameplay math and tables

- Status: accepted
- Date: 2026-11-01

## Context

Floating point differences and `pow` implementations differ across C++ and the JVM.

## Decision

Gameplay values are integers (percent, permille, `_x100` fields). Curves such as XP are data tables generated by the reference.

## Consequences

Identical results on all clients; balance tweaks need no code changes.
