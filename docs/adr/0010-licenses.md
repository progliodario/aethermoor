# ADR 0010: Licenses

- Status: accepted
- Date: 2026-11-01

## Context

The project is public and open source, and mods are expected.

## Decision

Code: GPL-3.0-or-later. Content (`data/`, `docs/design/`): CC BY-SA 4.0 (to be confirmed by the owner). Contributions use the DCO. Dependencies must be GPLv3-compatible.

## Consequences

Strong copyleft for code; remixable content. Distribution on Google Play is allowed because the source is public.
