# ADR 0011: Project languages

- Status: accepted
- Date: 2026-11-01

## Context

The owner works in Italian; contributors and tools work best in English.

## Decision

Code, file names, commits, `docs/spec` and `docs/dev` in English. `docs/design` and the main README in Italian (with `README.en.md`). In-game text in Italian and English via i18n keys.

## Consequences

Creative work stays in the owner's language; technical work stays accessible.
