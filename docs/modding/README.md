# Modding

Mods are content packs: a folder with a `pack.json` and data files that follow the schemas in `schemas/`. No code, no scripting. See `docs/plan/02-dati-specifiche-e-formati.md` (section 12) for what is and is not possible.

The JSON reference will be generated from the schemas by `tools/gen_schema_docs.py` (planned).
