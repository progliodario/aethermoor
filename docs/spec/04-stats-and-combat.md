# 04. Stats and combat

Status: **v1 (formulas only)**. Reference: `tools/reference/rules.py`. Conformance suites: `stats`, `damage`, `xp`.
Hitboxes, timing, dodge/parry and status effects are specified in M3.

## Primary stats

`str`, `vit`, `dex`, `agi`, `int`, `wis`, `luk`: non-negative integers.

## Derived stats

Integer division is floor division. Rates are per mille (`_pm`), speeds and regeneration are hundredths (`_x100`).

| Name | Formula |
|---|---|
| `max_hp` | `50 + vit*12 + level*8 + equip.hp` |
| `max_mp` | `20 + wis*8 + int*3 + level*3 + equip.mp` |
| `atk` | `str*2 + dex/2 + equip.weapon_atk` |
| `matk` | `int*2 + wis/2 + equip.weapon_matk` |
| `def` | `vit*12/10 + equip.armor_def` |
| `mdef` | `wis*12/10 + equip.armor_mdef` |
| `move_speed_x100` | `400 * (1000 + min(agi*2, 400)) / 1000` (tiles per second x100) |
| `attack_speed_pm` | `min(1000 + agi*4 + dex*2, 2000)` |
| `crit_chance_pm` | `min(50 + luk*15 + dex*10, 600)` |
| `crit_mult_pm` | `min(1500 + luk*3, 2500)` |
| `status_resist_pm` | `min(wis*3 + luk, 750)` |
| `mp_regen_x100` | `50 + wis*5` (per second x100) |

## Damage

Inputs: `atk` (ATK or MATK of the attacker), `power_pct`, `def_target` (DEF or MDEF), `elem_mult_pm`
(1500 weakness, 1000 neutral, 500 resistance), `pen_pm` (defense penetration), `lvl_attacker`, `lvl_target`,
`variance_pm` (random 950..1050 from the `combat` stream), `crit` (bool), `crit_mult_pm`, `buff_mod_pm`.

```
raw       = atk * power_pct / 100
elem      = raw * elem_mult_pm / 1000
def_eff   = def_target * (1000 - pen_pm) / 1000
mitigated = elem * 100 / (100 + def_eff)
lvl_mod   = clamp(1000 + 30 * (lvl_attacker - lvl_target), 700, 1300)
x = mitigated * lvl_mod / 1000
x = x * variance_pm / 1000
x = x * (crit ? crit_mult_pm : 1000) / 1000
x = x * buff_mod_pm / 1000
damage    = max(1, x)
```

Every `/` is a floor division, applied at each step (the order matters and is part of the contract).

## Experience

- The XP needed to go from level `L` to `L+1` is read from the table `base:table/xp` (levels 1 to 98; `values[L-1]`).
  The table is generated by `tools/gen_tables.py` from `floor(30 * L^1.6 + 20 * L)`; **clients never evaluate the power**.
- `xp_gain = enemy_xp * clamp(1000 + 100 * (lvl_enemy - lvl_player), 100, 1500) / 1000`.
- Maximum level: 99.

## Difficulty

The world data may have `difficulty {enemy_hp_pct, enemy_atk_pct}` (percent, default 100 each, 10 to 2000). The clients scale the `hp` (at least 1) and the `atk` of every creature of the streamed world when they load its
definition (integer division by 100); nothing else changes, and maps without a world (the demo, the conformance scenarios) are not affected. The base pack sets 100 percent health and 70 percent attack (the owner's choice of 2026-11-10: the protagonist of an isekai is overpowered, so fights must be too easy; with it a creature of the player's level falls in about a second and costs a few points of health, and what `docs/design/balance.md` calls outliers are creatures that are easier than their level, which is wanted). From 2026-11-06 to that day it was 200 and 175. It is the one number to change to make every fight longer or harder,
until the numbers of the creatures themselves are tuned (`docs/design/balance.md`).
