# Glossary

| Italian | English | Meaning |
|---|---|---|
| Dono | Gift | The protagonist's "cheat" |
| Soglia | Threshold | Place/force of Lyra between worlds; checkpoint stones |
| Pietra della Soglia | Threshold Stone | Checkpoint, save point and fast-travel node |
| Echi (dell'anima) | Echoes | Meta-currency earned on reincarnation |
| Albero dell'Eredità | Legacy Tree | Meta-progression tree kept across lives |
| Ospite | Guest / Wanderer | Soul summoned from another world |
| Marea Oscura | Dark Tide | Cyclic threat that the Demon King leads |
| Finestra di stato | Status window | In-game system window with stats |
| Titolo | Title | Earned honorific with small bonuses |
| Tag | Tag | State/trait label that drives dialogue and small rules |
| Gilda | Guild | Adventurers' guild with ranks F to S |
| Legame | Bond | Affinity with an NPC or companion (0 to 10) |
| Aure | Aurei | Currency |
| Ricetta (d'arte) | Art recipe | JSON description of vector art |
| Pack | Pack | Content package with a `pack.json` |
